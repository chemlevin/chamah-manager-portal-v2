# Table: budget_categories

Status: Schema Freeze v1.

Last updated: 2026-07-13

## Purpose

Stores stable financial planning and reporting categories.

## Category Types

Allowed `category_type` codes:

- `INCOME`
- `EXPENSE`
- `INTERNAL_OFFSET`
- `MANUAL_UNDEFINED`

`PAYROLL` is not a category type in Schema Freeze v1.

## Handbook Traceability

Supports Budgeting BR-0050 through BR-0055 and Master Data BR-0159 through BR-0165.
