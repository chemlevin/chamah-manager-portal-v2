# CHAMAH Domain Pipeline Matrix

Status: authoritative Phase C map. This document describes verified repository/live contracts and explicitly marks missing paths. It does not authorize a write, migration, deployment, real-file upload, or future MCP implementation. Governance precedence remains `AGENTS.md` → `CHAMAH_SYSTEM_RULES.md` → `CHANGE_CONTROL.md` → `CHAMAH_RUNTIME_REGISTRY.md`.

## Common contract

All canonical operational ingestion is intended to follow `PROPOSED → PREVIEWED → RECONCILED → APPROVED → COMMITTED → VERIFIED`. Durable previews use `mcp_ingestion_batches`; ephemeral previews are explicitly identified. Stable identifiers are required; spreadsheet row position is never a match key. Unknown, ambiguous, duplicate, or conflicting identities remain unresolved/quarantined and cannot silently create master entities. Every source-backed path must preserve source filename/row, report/month, original and normalized values, payload, digest, batch/approval/commit/read-back IDs, and audit evidence.

Format legend: CSV/XLS/XLSX/PDF/HTML are marked only when a parser or runtime path was found. `MCP` means structured payload, not a file parser. `Portal` means manual UI input. `—` means no verified support.

Readiness legend: `READY_FOR_READ_ONLY_ANALYSIS`, `READY_FOR_PREVIEW`, `READY_FOR_APPROVAL_AND_COMMIT`, `PARTIAL`, `NOT_READY`, `BLOCKED`, `NOT_APPLICABLE`.

## Cross-cutting gaps and controls

1. No complete verified parser matrix exists for PDF, RTL extraction, HTML, or large files across all domains. Those formats are not silently treated as supported.
2. Workforce, bank, supplier, payment, payroll, and several financial paths contain preview/read or approval-bound pieces but not a complete domain-specific file-to-commit proof; they remain `READY_FOR_PREVIEW` or `PARTIAL`.
3. No domain is classified `READY_FOR_APPROVAL_AND_COMMIT` in this matrix because a complete parser/source-to-read-back proof is not established for the whole domain.
4. Legacy portal/Edge Function direct-write callers are catalogued in `docs/PORTAL_CALLER_INVENTORY_SYSTEM_MAPPING.md`; hardened paths fail closed before database dispatch, while valid read-only behavior remains available.
5. Site/deployment Preview and business-data Preview batches are separate concepts. A deployed Preview site does not authorize a business-data write.
6. A failed read-back, unknown commit, unresolved identifier, ambiguous match, duplicate, or wrong environment leaves the domain non-verified and blocks blind retry.
