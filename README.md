# chamah-manager-portal

פורטל מנהלות חמ״ה. כרגע מודול מחשבון השכר פעיל, ושאר המודולים משמשים כעמודי הכנה.

## Developer Documentation

Future developers and AI agents should read these files before making changes:

1. `AGENTS.md`
2. `PROJECT_LOG.md`

## הרצה מקומית

```bash
npm run build
npm start
```

## פרסום ב-Vercel

הפרויקט כולל `vercel.json`. Vercel יריץ `npm run build` ויגיש את תיקיית `dist`.
